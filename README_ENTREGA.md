# Entrega - Creación de un Juego Interactivo con ChatGPT

Esta carpeta está organizada para subirla completa a Google Drive.

| Requisito de la evaluación | Archivo o carpeta |
| --- | --- |
| Demo funcional | `demo-juego/index.html` |
| Código HTML, CSS y JavaScript | `demo-juego/` |
| Documento con código comentado y reflexión | `documentacion/Documento_del_proyecto.docx` y PDF |
| Video corto de proceso | `video/guion_video.md` |
| Publicación en GitHub Pages | `.github/workflows/deploy-pages.yml` y `documentacion/publicar_en_github.md` |

## Orden recomendado

1. Sube la carpeta `demo-juego` a un repositorio nuevo de GitHub.
2. Sube también `.github/workflows/deploy-pages.yml` al mismo repositorio.
3. En GitHub entra a **Settings > Pages**, selecciona **GitHub Actions** como fuente. Al terminar la acción, GitHub mostrará el enlace público.
4. Usa ese enlace en WebIntoApp para solicitar el APK Android. Si el profesor exige Tiiny Host, sigue la alternativa incluida en la documentación.
5. Graba el video usando el guion y sube toda la carpeta a Drive.
