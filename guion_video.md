# Guion de video corto (60-90 segundos)

1. **Presentación (0:00-0:10).** “Nuestro juego se llama *Metro Maze: Rescue Circuit*. Es un laberinto interactivo original de cinco niveles hecho con HTML, CSS y JavaScript.”
2. **Demo (0:10-0:35).** Mostrar movimiento, un núcleo, una pulso-carga que abre una caja y el portal. “El objetivo es obtener todos los núcleos y alcanzar la salida sin perder las tres vidas.”
3. **Proceso con ChatGPT (0:35-0:55).** “Usamos ChatGPT para planificar la cuadrícula, generar la base de HTML/CSS/JavaScript y revisar la lógica de colisiones, bombas, enemigos y controles táctiles. Luego probamos y ajustamos el diseño.”
4. **Diseño y publicación (0:55-1:15).** “Diseñamos una interfaz móvil con colores y elementos originales, sin copiar recursos de otros juegos. El proyecto se publica como sitio web y puede convertirse en APK mediante WebIntoApp.”
5. **Cierre (1:15-1:25).** “Aprendimos a dividir un problema grande en mecánicas pequeñas, probar cada una y documentar cómo la IA apoyó el desarrollo.”
